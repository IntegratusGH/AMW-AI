When enabled, each configured validate box is OCR'd (with this template's image settings) before cropping; the template is used only if the read text matches the validate text/pattern. If a second box is configured, BOTH boxes must match (logical AND). Otherwise the fail template is tried. If none match, that slip is flagged “Error” and skipped, and processing continues with the next slip. Plain text is matched loosely (tolerates minor OCR errors). Wildcards: * any run, ? one letter, # one digit, [abc]/[a-c] a set/range, [!abc] excludes; combine patterns with and/or/not (e.g. *cash* or *cheque*).
